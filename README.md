# CMYK Impresiones - Portafolio informativo

Este paquete está listo para subir a un repositorio de GitHub y publicar con GitHub Pages.

## Archivos
- `index.html`
- `logo.png`
- `.nojekyll`

## Cómo publicarlo en GitHub Pages
1. Crear un repositorio nuevo en GitHub.
2. Subir el contenido de esta carpeta a la raíz del repositorio.
3. Ir a **Settings > Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Elegir la rama principal y la carpeta `/root`.
6. Guardar los cambios y esperar la publicación.
